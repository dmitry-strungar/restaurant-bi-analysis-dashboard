# BI-анализ сети ресторанов

Проект Power BI, направленный на анализ поведения клиентов, сегментацию и оценку эффективности работы сети ресторанов.

---

## Обзор проекта

Данный проект анализирует данные о продажах и клиентах сети ресторанов для оценки:

- Активности и вовлеченности клиентов
- Выручки по городам и ресторанам
- Сегментации клиентов (Light / Medium / Hard)
- Среднего чека и цен на продукты (без НДС)
- LTV (Lifetime Value)
- Распределения выручки по ресторанам

Цель проекта — создать интерактивные аналитические дашборды для принятия бизнес-решений.

---

## Источники данных

Анализ основан на двух наборах данных:

1. **Клиенты**
   - Дата регистрации
   - Дата рождения
   - Пол
   - Город
   - Информация о программе лояльности

2. **Продажи**
   - ID транзакции
   - Информация о ресторане
   - Категория продукта
   - Цена продукта (с НДС)
   - Количество
   - Дата транзакции
   - Общая сумма чека

НДС = 18%. Все финансовые показатели рассчитаны без учета НДС.

---

## Моделирование данных

- Модель «звезда» (Star schema)
- Таблица фактов: Sales
- Таблицы измерений: Клиенты, Рестораны, Блюда, Календарь
- Расчетные показатели реализованы с использованием DAX
- Возраст рассчитан на момент совершения транзакции
- Сегментация клиентов основана на количестве визитов в месяц

---

## Ключевые метрики

- Уникальные клиенты
- Количество транзакций
- Средний чек (без НДС)
- Выручка (без НДС)
- Среднее количество транзакций в месяц
- Средняя цена продукта
- LTV
- Доля выручки по ресторанам

---

## Логика сегментации клиентов

Клиенты сегментируются на основе среднего количества визитов в месяц:

- **Light**: < 0.5 визита в месяц  
- **Medium**: 0.5 – 1.5 визита в месяц  
- **Hard**: > 1.5 визита в месяц

4. Анализ продуктов и выручки  

Реализованы интерактивные закладки для переключения между:

- Транзакциями
- Средним чеком
- Выручкой

## Ключевые инсайты

- **Клиенты сегмента Hard являются ключевым драйвером выручки.**  
  При среднем LTV около 38 000 ₽ и формировании до 100% выручки выбранного сегмента, именно этот кластер обеспечивает основную прибыльность бизнеса. Удержание данных клиентов критично для стабильности доходов.

- **Сегмент Medium — основной источник масштабируемого роста.**  
  Динамика транзакций показывает устойчивое увеличение активности, что делает данный сегмент приоритетным для апселла и программ лояльности.

- **Наблюдается концентрация выручки в ограниченной группе клиентов.**  
  Топ-10 клиентов формируют **27,3% общей выручки (≈50,9 млн ₽ из 186,5 млн ₽)**, что создаёт умеренный риск зависимости от крупных покупателей.

- **Существенные различия в региональной эффективности.**  
  Средний уровень цены по городам:
  - Москва — ~109,4  
  - Санкт-Петербург — ~93,6  
  - Ростов-на-Дону — ~54,8  
  Разрыв отражает различия в покупательской способности и ценовой эластичности спроса.

- **Операционный дисбаланс между ресторанами.**  
  Часть точек демонстрирует высокий объём транзакций при среднем чеке около **1 358 ₽**, что указывает на потенциал оптимизации ценовой политики и товарной матрицы.

- **Положительная динамика привлечения клиентов.**  
  В конце периода наблюдается резкий рост новых покупателей, при этом общая выручка достигает **186 534 458 ₽**, подтверждая ускорение бизнес-динамики.

- **Поведение клиентов структурно сегментировано.**  
  Существенные различия в LTV и среднем чеке подтверждают необходимость дифференцированной стратегии удержания и коммуникации.

### Управленческие выводы

Дашборды позволяют:

- Контролировать риск концентрации выручки  
- Выявлять сегменты с максимальным LTV  
- Оптимизировать ценовую стратегию по городам и точкам  
- Сравнивать эффективность ресторанов  
- Реализовывать data-driven подход к маркетингу и сегментации
